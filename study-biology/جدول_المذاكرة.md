## ⏱️ الإيقاع اليومي (١٠ص – ١٠م)
```
١٠:٠٠–١٢:٥٠  ٣ جلسات (٥٠+١٠)         ← مادة جديدة
١:٠٠–٢:٠٠    🍽️ غداء وراحة كبيرة
٢:٠٠–٤:٥٠    ٣ جلسات                  ← مادة جديدة + رسومات
٤:٥٠–٥:٣٠    راحة كبيرة
٥:٣٠–٧:٢٠    جلستان                   ← تكملة / بداية الفصل التالي
٧:٢٠–٨:٢٠    🍽️ عشاء وراحة
٨:٢٠–١٠:٠٠   جلستان                   ← تسميع (Active Recall) + حل أسئلة
```
**~٨ جلسات × ٥٠ دقيقة ≈ ٧–٨ ساعات دراسة فعلية.**

---

## 🎯 قواعد ثابتة كل يوم
1. بعد كل جلسة: **اقفل الملزمة وسمّع براسك**.
2. آخر جلستين دائماً **حل أسئلة بدون نظر للجواب** ثم صحّح.
3. ابدأ كل يوم بـ**تسميع سريع** للفصل السابق (١٥–٢٠ دقيقة).
4. الموبايل بعيد أثناء الـ٥٠ دقيقة.
5. نوم ٧–٨ ساعات — ضروري للحفظ.
